# MARS VIBE — инструкция по установке

## Что внутри
- `index.html` — структура страницы
- `style.css` — оформление
- `script.js` — плеер и список треков (плейлист редактируется здесь)
- `audio/` — сюда кладёшь mp3-файлы
- `covers/` — сюда (не обязательно) кладёшь обложки треков

## Шаг 1. Замени файлы в репозитории
В своём репозитории `mars-vibe-music` на GitHub удали старый `index.html`
и добавь эти четыре файла и две папки вместо него (сохраняя структуру).

## Шаг 2. Переименуй mp3-файл
Твой текущий файл называется:
`AFTER MIDNIGHT _ Night Drive 🌙.mp3`

Пробелы и эмодзи в названии файла часто ломают ссылки на GitHub Pages.
Переименуй его в:
`after-midnight-night-drive.mp3`

и положи в папку `audio/`. Это имя уже прописано в `script.js`, так что
менять код не нужно — если оставишь ровно такое имя, всё заработает сразу.

## Шаг 3. Как добавить ещё треки
Открой `script.js`, найди массив `TRACKS` в самом верху файла и добавь
новую строку по образцу:

```js
const TRACKS = [
  {
    title: "After Midnight",
    artist: "Night Drive",
    src: "audio/after-midnight-night-drive.mp3",
    cover: ""
  },
  {
    title: "Название нового трека",
    artist: "Автор",
    src: "audio/имя-файла.mp3",
    cover: "covers/имя-обложки.jpg" // необязательно
  }
];
```

Список на сайте и плеер обновятся автоматически — больше ничего
редактировать не нужно.

## Шаг 4. Залей на GitHub
Если работаешь через сайт GitHub: просто перетащи файлы в репозиторий
через "Add file → Upload files" и нажми "Commit changes".

Если через терминал:
```bash
git add .
git commit -m "Новый дизайн и плеер"
git push
```

Через 1–2 минуты изменения появятся на
`https://themarsing06-spec.github.io/mars-vibe-music/`.

## Что умеет сайт
- Список треков с длительностью, кликабельный
- Закреплённый плеер внизу экрана: play/pause, следующий/предыдущий трек
- Перемотка и регулировка громкости (громкость запоминается)
- Управление с экрана блокировки телефона (кнопки play/pause в шторке)
- Пробел на клавиатуре = play/pause
- Адаптивная вёрстка под телефон

## Если что-то не играет
- Проверь, что имя файла в `src` в `script.js` **точно** совпадает
  с именем файла в папке `audio/` (регистр букв важен).
- В названиях файлов лучше не использовать кириллицу, пробелы и эмодзи —
  латиница, цифры и дефисы работают надёжнее всего.
